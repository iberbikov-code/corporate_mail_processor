# Умная сортировка корпоративной почты 

Мы представляем проект для хакатона по Технологиям программирования (НИУ ВШЭ).
Была написана программа, которая помогает IT-отделу автоматически разбирать завалы входящих писем. Скрипт читает файлы из папки, понимает по ключевым словам, о чем они, и аккуратно раскладывает по нужным категориям.

## Как работает сортировка
Система анализирует текст и распределяет письма по 5 основным папкам:
* **critical_incidents** — Упал сервер, сломалась база данных (самое важное и срочное).
* **access_management** — Просьбы выдать доступ, пароли, настроить VPN.
* **hardware_issues** — Сломался принтер, мышка, монитор (технические проблемы, решающиеся вмешательством человека).
* **hr_finance_docs** — Бухгалтерия, чеки, больничные (то, что прислали в IT по ошибке).
* **security_phishing** — Спам, фишинг, подозрительные ссылки.

**Защита от сбоев (quarantine):** В реальной почте часто попадаются картинки, битые файлы или системный мусор (например, .DS_Store). Наша программа от этого не ломается. Она умеет перехватывать такие файлы и переносить их в папку quarantine, чтобы потом с ними разобрался человек.

## Структура проекта
* `src/` — исходный код на Python (тут лежит сама логика сортировки).
* `tests/` — автотесты для проверки надежности кода.
* `inbox/` — сюда нужно положить входящие письма для проверки (саму папку игнорирует .gitignore).
* `output/` — здесь появятся отсортированные папки после запуска скрипта.
* `run_mail_processor.sh` — Bash-скрипт для быстрого запуска программы.
* `src/config.json` — словарь ключевых слов для сортировки (можно легко менять без изменения кода).

## Модуль расширения: Интерактивная аналитика и Docker (На 10 баллов)
Для получения максимальной оценки реализовано осмысленное расширение поверх базовой логики. Вместе с AI мы разработали интерактивный веб-дашборд на фреймворке Streamlit для визуализации бизнес-метрик (распределение писем, просмотр текстов критических инцидентов) и упаковали весь проект в Docker-контейнеры для запуска "одной кнопкой".

Инструкции по запуску этого модуля находятся ниже в Шаге 8.

## Как запустить проект (Подробная инструкция)

### Шаг 1. Откройте командную строку
* **На macOS / Linux:** Нажмите поиск (Command + Space) и введите Terminal (Терминал).
* **На Windows:** Нажмите поиск в пуске и введите cmd (Командная строка) или PowerShell.

### Шаг 2. Убедитесь, что установлен Python
В открывшемся окне введите команду и нажмите Enter:
```bash
python3 --version
```
> *(Если система пишет, что команда не найдена, попробуйте написать просто `python --version`)*. 
Если Python не установлен — скачайте его с официального сайта python.org. Нужна версия 3.9 или новее.

### Шаг 3. Скачайте проект на свой компьютер
В том же терминале по очереди введите эти две команды:
```bash
git clone https://github.com/iberbikov-code/corporate_mail_processor.git
cd corporate_mail_processor
```
> Если программа git не установлена — зайдите на страницу нашего репозитория в браузере, нажмите зелёную кнопку Code → Download ZIP, распакуйте архив и перейдите в эту папку через ваш терминал.

### Шаг 4. Настройте окружение
Чтобы программа работала стабильно, скачаем нужные библиотеки. Выполните эти команды по очереди:

**Для macOS / Linux:**
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

**Для Windows:**
```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

### Шаг 5. Положите письма в папку inbox/ (Обязательно)
Чтобы программе было что сортировать, нам нужно добавить сами письма.
1. Откройте папку `corporate_mail_processor` через обычный файловый менеджер (Finder на Mac или Проводник на Windows).
2. Создайте внутри новую папку и назовите её `inbox`.
3. Возьмите выданный вам на хакатоне архив `inbox.zip`, распакуйте его и скопируйте все письма прямо в эту созданную папку `inbox`.
> **Внимание:** Мы намеренно не стали загружать письма на GitHub в целях безопасности (папка скрыта в `.gitignore`). Без реальных писем программа просто завершит работу.

### Шаг 6. Запустите программу (Базовая часть)
Вернитесь в терминал и запустите сортировку:

**Вариант А — через Bash-скрипт (Только для macOS/Linux):**
```bash
chmod +x run_mail_processor.sh
./run_mail_processor.sh
```

**Вариант Б — вручную через Python (Работает везде):**
Убедитесь, что в терминале слева горит надпись `(.venv)` и введите:
```bash
python3 src/main.py
```

### Шаг 7. Посмотрите результат
После запуска скрипта в папке нашего проекта автоматически появится новая папка `output/`. Откройте её — внутри вы увидите подпапки с аккуратно отсортированными письмами и папку quarantine для бинарного мусора.

### Шаг 8. Запуск модуля на 10 баллов (Дашборд аналитики)
Вы можете посмотреть интерактивную аналитику по отсортированным письмам двумя способами:

**Вариант А — Быстрый запуск через Docker:**
Убедитесь, что запущен Docker Desktop. В корне проекта введите команду:
```bash
docker compose up --build
```
Дождитесь сборки и перейдите в браузере по ссылке: **http://localhost:8501**

**Вариант Б — Локальный запуск (если нет Docker):**
При активированном виртуальном окружении выполните:
```bash
python3 -m streamlit run extension/dashboard.py
```
Браузер автоматически откроет красивый отчет.

## Запуск автотестов
Мы покрыли код тестами pytest, чтобы доказать, что классификатор работает без ошибок, а бинарные файлы не ломают систему. Для запуска проверок введите в терминал:
```bash
python3 -m pytest tests/ -v
```
